grok.me Public Catalog Monitor

The job
Read-only sweep of the public *.grok.me surface: the community directory, CT logs, X mentions and the owner’s own registry. Flags remixes, naming overlaps and any family host that is not returning 200.
Tools
Grok Bot, curl, X API search, directory.grok.me
